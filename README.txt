ONLINE BOOK STORE — WEB TECHNOLOGY LAB PROJECT

HOW TO RUN
1. Extract this ZIP into a folder.
2. Open index.html in Chrome/Edge/Firefox.
3. Use the top navigation and left department links. Pages load in the main frame.
4. Add books from Catalogue or a department page. Open Cart to change quantities, remove books, clear cart, and try the demo checkout.
5. Registration, Login, Experiment 6 and Experiment 7 forms validate in the browser.

FILES
- index.html, top.html, left.html, home.html: three-frame home layout based on the lab PDF.
- login.html, registration.html, catalogue.html, cart.html: working demo pages.
- cse.html, ece.html, eee.html, civil.html: department-specific catalogue pages.
- experiment6-validation.html, experiment7-validation.html, experiment8-css-backgrounds.html, experiment9-css-links.html: lab practicals.
- styles.css, store.js: shared styling and cart functions.
- assets/: extracted logo/book-cover crops from the PDF screenshots, plus local background SVGs.

IMAGE NOTE
The supplied PDF contains rendered screenshots of the book covers and store logo, which have been cropped into local image assets. It refers to separate background.jpg / box-background.jpg / pattern.jpg files, but those original JPG files were not embedded in the PDF. Matching local SVG background files are included so there are no broken images.

The login/registration/checkout are front-end demonstrations only. No server, account database, or real payment is connected.
